
 Учебный проект " Развёртывание через CI/CD "

 В этом проекте для ранее разработанного Django-приложение с API для создания и управления ботами я  настроил VPS и создал CI/CD пайплайн с использованием GitHub Actions, который  автоматически собирает Docker-образ приложения, публикует его в GitHub Container Registry, подключаеся к VPS по SSH и перезапускает Docker-контейнер с новым образом по адресу 109.120.159.190:80/admin или /api (зайти можно root пароль 123)
