
 Учебный проект " Развёртывание через CI/CD "

 В этом проекте для ранее разработанного Django-приложение с API для создания и управления ботами я  настроил VPS и создал CI/CD пайплайн с использованием GitHub Actions, который  автоматически собирает Docker-образ приложения, публикует его в GitHub Container Registry, подключаеся к VPS по SSH и перезапускает  Docker-контейнер с новым образом по  адресу ( для реализации проекта арендовался VPS)
